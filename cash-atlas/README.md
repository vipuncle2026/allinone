# 存放 Cash Atlas

面向中国大陆个人人民币现金的严格本金边界筛选网页。研究快照：2026-11-16。

## 打开与转发

- 直接用桌面浏览器打开`index.html`。所有计算逻辑、样式、数据和研究笔记内嵌，无需安装依赖或联网运行。
- 可直接发送这个HTML文件；手机聊天软件可能不运行脚本，应保存后用系统浏览器打开。
- 给朋友一个真正的网页链接：将`index.html`上传到你控制的静态网站托管；本机的127.0.0.1地址不能对外分享。此项目尚未公开部署。
- 在线查证外部原文仍需互联网。下载研究笔记在单文件离线状态也可用。
- 不上传、持久化或追踪输入。分享按钮复制不含金额的空白工具网址。导出JSON含个人金额，不应直接转发。

## 开发与测试（Node 18+，无第三方包）

```sh
node cash-atlas/build.mjs
node cash-atlas/test.mjs
python3 -m http.server 4176 --bind 127.0.0.1 --directory cash-atlas
```

在项目父目录运行；浏览器打开 http://127.0.0.1:4176/ 。

- `data.mjs`：来源、产品样本、法律属性、门槛和报价。
- `engine.mjs`：可独立复算的纯函数门槛、评分、额度和费用计算。
- `app.mjs`：交互与展示。
- `index.template.html`、`styles.css`：页面结构和响应式设计。
- `build.mjs`：将全部资源及RESEARCH.md内嵌为单文件。
- `RESEARCH.md`：研究结论、数据边界、完整公式与证据目录。
- `evidence/manifest.json`：实际保存的文件校验值；动态页快照限制见evidence/README.md。

## 不可误读的边界

59个样本/家族不是全国全部当日可购SKU。具体普通存款报价只核实中行、兴业，不称全市场最高。非保本或不符合退出条件的产品N/A；未知参数不编造分数。储蓄国债只有票面报价，完整可比现金流/额度未核实，不评分。主榜仍须交易前确认账户、实际执行价、额度和到账规则，不是保证成交。

默认权重是公开的偏好模型，不是监管评级或统计风险概率。没有产品能承诺任何故障/冻结/机构风险处置状态下仍T+0；保本口径也不保护通胀损失。本模型不是自动交易服务，不代替个人审慎核验。
