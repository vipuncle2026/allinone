# 证据文件说明

查阅/保存基准：2026-11-16。

- `*.pdf`：下载的银行原始说明书。`cash-*.txt`为PDF文本提取物。
- `*.raw.txt`：原始HTTP响应字节，后缀用txt便于离线审阅；不是重新整理的网页。
- `cib-data.json`：兴业官网利率页引用的同域公开数据响应，保留原始JSON。
- 其他`*.txt`：初始抓取/清洗后的研究工作文本，不应当作官方签名副本。
- `manifest.json`为当前实际文件的字节数、SHA-256、原始地址（已建立映射者）、保存基准日。无映射的辅助工作文本不作为独立报价来源；正式来源目录见上级RESEARCH.md。

静态HTML可能不包含动态渲染的实时数据。逆回购定盘值和部分基金页面值经浏览器查阅；静态快照不等于完整逐笔行情审计包。证书报错的基金官网不用于证明当周净值。哈希只能证明本地文件一致性，不证明官方签名、现时可购或最终成交。

本研究没有登录用户账户、截图个人资产、获取客户专属报价或核实当日库存。
